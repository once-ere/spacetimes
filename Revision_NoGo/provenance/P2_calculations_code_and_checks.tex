\hypertarget{what-this-document-is}{%
\section{1. What this document is}\label{what-this-document-is}}

This document states, for every computation of the folder
\texttt{Revision\_NoGo}, the formulas that the program evaluates, how it
evaluates them, the command that runs it, and the complete output of
every check, as the program printed it in the last run. Section 2 says
how to reproduce everything; Section 3 describes the program; Sections 4
to 9 go through its six commands; Section 10 reproduces the checks of
the documents; Section 11 lists the data files and figures; Section 12
gives the checksums; Section 13 is the complete table of the symbols,
which defines every symbol used here.

\hypertarget{how-to-reproduce-everything}{%
\section{2. How to reproduce
everything}\label{how-to-reproduce-everything}}

From the folder \texttt{Revision\_NoGo} of the repository:

\begin{verbatim}
cargo run --release --manifest-path code/nogo-rs/Cargo.toml -- all   # data files and checks of the program
python3 code/scripts/make_figures.py                                 # the thirteen figures
bash code/scripts/check_all.sh                                       # everything, with one verdict
\end{verbatim}

\texttt{check\_all.sh} runs, in this order: the program (all six
commands); the figures; twice in a row the registry of the symbols, the
fragments of the documents, the checks of the symbols, the assembly of
the Markdown documents, the manuscript (.tex, .pdf, .md) and the
provenance documents (.tex, .pdf), and the check of self-containedness
(the second pass makes every document contain the reports of the first);
then it searches the documents for the names of software tools that do
not belong in a manuscript and prints one verdict, ``ALL PASS'' or the
list of failures. Requirements: a Rust toolchain for the edition 2021;
Python 3 with NumPy and Matplotlib; TeX Live with REVTeX 4.2, XeLaTeX
and latexmk, the DejaVu fonts and the Latin Modern Math font; pandoc.
The program refuses to run unless it is started in the folder
\texttt{Revision\_NoGo} (it writes its data files into \texttt{data/} of
the current folder).

\hypertarget{command-octonions}{%
\section{\texorpdfstring{4. Command
\texttt{octonions}}{4. Command octonions}}\label{command-octonions}}

\textbf{The algebras.} Quaternions \(\mathbb H_{\rm NG}\):
\(\mathsf x=\sum_{p=0}^3\mathsf x^p\mathsf e_p\) with
\(\mathsf e_1^2=\mathsf e_2^2=\mathsf e_3^2=-1\),
\(\mathsf e_1\mathsf e_2=-\mathsf e_2\mathsf e_1=\mathsf e_3\) and
cyclic permutations. The Cayley-Dickson double: pairs of quaternions
with
\[(\mathsf x_1,\mathsf x_2)(\mathsf y_1,\mathsf y_2)=(\mathsf x_1\mathsf y_1+\varsigma_{\rm NG}\,\bar{\mathsf y}_2\mathsf x_2,\ \mathsf y_2\mathsf x_1+\mathsf x_2\bar{\mathsf y}_1),\qquad \overline{(\mathsf x_1,\mathsf x_2)}=(\bar{\mathsf x}_1,-\mathsf x_2),\]
with \(\varsigma_{\rm NG}=-1\) (octonions \(\mathbb O_{\rm NG}\)) or
\(+1\) (split octonions \(\mathbb O'_{\rm NG}\)), basis
\(\mathsf e_0,\dots,\mathsf e_3=(\mathsf e_p,0)\),
\(\mathsf e_4=(0,1)\), \(\mathsf e_5=(0,\mathsf e_1)\),
\(\mathsf e_6=(0,\mathsf e_2)\), \(\mathsf e_7=(0,\mathsf e_3)\). The
program builds the integer table of the 64 products of basis elements
(data file \texttt{ng\_octonion\_tables.csv}) and computes everything
else from it in exact arithmetic.

\textbf{What it computes.} The norm
\(N_{\rm NG}(\mathsf x)=\mathsf x\bar{\mathsf x}\) and its polarization
\(\langle\mathsf x,\mathsf y\rangle_{\rm NG}\); the composition law
\(N_{\rm NG}(\mathsf x\mathsf y)=N_{\rm NG}(\mathsf x)N_{\rm NG}(\mathsf y)\)
in its fully polarized form
\(\langle\mathsf x\mathsf y,\mathsf z\mathsf w\rangle_{\rm NG}+\langle\mathsf x\mathsf w,\mathsf z\mathsf y\rangle_{\rm NG}=2\langle\mathsf x,\mathsf z\rangle_{\rm NG}\langle\mathsf y,\mathsf w\rangle_{\rm NG}\)
on all \(8^4\) quadruples of basis elements (both sides are multilinear,
so this proves it); the associator
\((\mathsf x,\mathsf y,\mathsf z)=(\mathsf x\mathsf y)\mathsf z-\mathsf x(\mathsf y\mathsf z)\)
on all 512 basis triples (total antisymmetry, the number of nonzero
values); the Moufang identities on 2000 random triples with integer
coefficients; the Jacobiator
\[\mathrm{Jac}_{\rm NG}(\mathsf x,\mathsf y,\mathsf z)=[[\mathsf x,\mathsf y],\mathsf z]+[[\mathsf y,\mathsf z],\mathsf x]+[[\mathsf z,\mathsf x],\mathsf y],\]
which in any algebra is the sum of the six associators of
\(\mathsf x,\mathsf y,\mathsf z\) in all orders, each with the sign of
the permutation, hence \(6(\mathsf x,\mathsf y,\mathsf z)\) in an
alternative algebra; the rank of the Jacobiators of the imaginary units
(7: they span all imaginary elements, so every linear map
\(\rho_{\rm NG}\) that turns commutators into commutators of operators
vanishes, because the Jacobiator of operators is zero); the Malcev
identity
\(\mathrm{Jac}_{\rm NG}(\mathsf x,\mathsf y,[\mathsf x,\mathsf z])=[\mathrm{Jac}_{\rm NG}(\mathsf x,\mathsf y,\mathsf z),\mathsf x]\).

The \textbf{derivations} \(\mathsf D\) (with
\(\mathsf D(\mathsf x\mathsf y)=(\mathsf D\mathsf x)\mathsf y+\mathsf x(\mathsf D\mathsf y)\))
are the null space of the 512 linear equations that this condition
imposes on the 64 entries of an \(8\times8\) matrix, written for all
pairs of basis elements; the program finds dimension 14 and computes the
Killing form
\(B_{\rm NG}(\mathsf D_1,\mathsf D_2)=\mathrm{tr}(\mathrm{ad}\,\mathsf D_1\,\mathrm{ad}\,\mathsf D_2)\)
exactly, then the signs of the eigenvalues of its \(14\times14\) matrix.
The \textbf{left multiplications}
\(L_{\rm NG}(\mathsf e_1),\dots, L_{\rm NG}(\mathsf e_7)\) generate
under commutators a Lie algebra whose dimension the program determines
by adding commutators until the rank stops growing (28).

\textbf{The octonionic Dirac matrices.} On \(7+1\), with the index map
\(u_{\rm NG}(4)=0\), \(u_{\rm NG}(j)=j\), \(u_{\rm NG}(0)=4\),
\(u_{\rm NG}(t)=t\),
\[\Gamma^4_{71\rm NG}=\begin{pmatrix}0&\mathsf 1_8\\ \mathsf 1_8&0\end{pmatrix},\qquad
\Gamma^A_{71\rm NG}=\begin{pmatrix}-L_{\rm NG}(\mathsf e_{u_{\rm NG}(A)})&0\\0&L_{\rm NG}(\mathsf e_{u_{\rm NG}(A)})\end{pmatrix}\ (A\ne4);\]
on \(4+4\),
\(\Gamma^A_{44\rm NG}=\begin{pmatrix}0&L_{\rm NG}(\bar{\mathsf e}_A)\\L_{\rm NG}(\mathsf e_A)&0\end{pmatrix}\).
The program checks the Clifford relations
\(\Gamma^A_{71\rm NG}\Gamma^C_{71\rm NG}+\Gamma^C_{71\rm NG}\Gamma^A_{71\rm NG}=2\eta^{AC}_{1671}\mathsf 1_{16}\)
and the same with \(\Gamma^A_{44\rm NG}\) and \(\eta^{AC}_{1644}\), that
\(\eta_{1671}(\mathsf x,\mathsf x)\) is the real part of the square of
the octonion
\(\mathsf x=x4\,\mathsf e_0+x1\,\mathsf e_1+x2\,\mathsf e_2+x3\,\mathsf e_3+ x0\,\mathsf e_4+x5\,\mathsf e_5+x6\,\mathsf e_6+x7\,\mathsf e_7\),
and that \(\eta_{1644}(\mathsf x,\mathsf x)\) is the split norm of
\(\mathsf x=\sum_AxA\,\mathsf e_A\). \textbf{The intertwiners}
\[\mathcal I_{71\rm NG}=\sum_K\Gamma^K_{71\rm NG}\,\mathsf U_{\rm NG}\,(\gamma^K_{1671})^{-1}\]
(sum over the 256 index sets; \(\mathsf U_{\rm NG}\) the first matrix
with one entry 1 and all others 0 that gives a nonzero sum), and
\(\mathcal I_{44\rm NG}\) in the same way, satisfy
\(\mathcal I_{71\rm NG}\gamma^A_{1671}=\Gamma^A_{71\rm NG}\mathcal I_{71\rm NG}\)
because multiplying the sum by \(\Gamma^A_{71\rm NG}\) on the left and
by \((\gamma^A_{1671})^{-1}\) on the right only permutes its terms (up
to signs that are the same on both sides). The program computes them in
integers (data files \texttt{ng\_intertwiner\_1671.csv},
\texttt{ng\_intertwiner\_1644.csv}) and their exact ranks.

\hypertarget{command-triality}{%
\section{\texorpdfstring{5. Command
\texttt{triality}}{5. Command triality}}\label{command-triality}}

\textbf{Local triality.} For each of the 28 basis elements
\(\mathsf m_1\) of \(\mathfrak{so}(N_{\rm NG})\) (the antisymmetric
matrices with respect to the norm), the condition
\[\mathsf m_1(\mathsf x\mathsf y)=(\mathsf m_2\mathsf x)\mathsf y+\mathsf x(\mathsf m_3\mathsf y)\]
for all 64 pairs of basis elements \(\mathsf x\), \(\mathsf y\) is a
system of 512 linear equations for the 56 coordinates of \(\mathsf m_2\)
and \(\mathsf m_3\) in \(\mathfrak{so}(N_{\rm NG})\). The program solves
it exactly and records the dimension of the solution space (0 for a
unique solution). The maps
\(T^{(2)}_{\rm NG}:\mathsf m_1\mapsto\mathsf m_2\) and
\(T^{(3)}_{\rm NG}:\mathsf m_1\mapsto\mathsf m_3\) are then
