# Purpose

Hard Rule 7 of the task specification forbids shortcuts and demands that problems be
explained. This file therefore records every error that was made while the project was
carried out, including errors that were corrected before anything was published. For
each error it states what was wrong, how it was detected, what was done, and where the
corrected statement can be checked. An error that is not listed here and is found later
is to be added, not silently repaired.

# Errors in the cosmological programs

All errors in this section were found by comparing the Rust solver with the code CLASS
(spectra of the author's NCSS project) *before* any cosmological result was committed;
none of them reached a document. They are recorded because the comparison is what
makes the final agreement (Supplement S3, Sec. 2) meaningful.

| No. | What was wrong | How it was found | Correction | Where to check |
|:--|:--------------------|:---------------|:----------------|:-----------|
| E15 | `spectra.rs`: wavenumbers above $\max(2.45\,\ell/\tau_0,\,0.012\ \mathrm{Mpc}^{-1})$ were not allowed to contribute to the multipole $\ell$. The projection of a wave of wavenumber $k$ contributes to all $\ell<k\tau_0$ with a slowly decaying weight, so power was lost: the temperature spectrum was too low by up to 14 per cent at $\ell=100$. | Comparison with CLASS. | The cut was removed; only the cut $\ell>1.02\,k\tau_0+10$ (where the spherical Bessel function is negligible) remains. | `spectra.rs`, comment in `compute` |
| E16 | `bessel.rs`: a unit test demanded an interpolation error of the Bessel table below $3\times10^{-7}/x$, which is stricter than the error bound $(h^4/384)\max|f''''|$ of cubic Hermite interpolation with the table's step $h=0.2$. The code was right and the test was wrong. | The test failed; the measured error was compared with the theoretical bound. | The test now checks the theoretical bounds of value and derivative, and a second test checks the differential equation. | unit tests `bessel::tests::table_interpolation_error_bounds`, `differential_equation` |
| E17 | `boltzmann.rs`: for the matter power spectrum at large wavenumbers the perturbations of the radiation were simply dropped at late times. In the synchronous gauge this is inconsistent: the frame moves with the dark matter, so the radiation has a bulk velocity $-k^2\alpha$ relative to it, and its momentum density is not small compared with that of the baryons. The matter power spectrum was 11 per cent too high for $k>0.33\ \mathrm{Mpc}^{-1}$. | Comparison of $P(k)$ with CLASS. | Replaced by the radiation-streaming approximation, which keeps these terms. | E18 | `cosmo.rs`: recombination was computed with the equations of RECFAST 1.0 (factor 1.14 for hydrogen, singlet channel only for helium), which lack the corrections that reproduce the modern multi-level calculations.
