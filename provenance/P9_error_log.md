# Purpose

Hard Rule 7 of the task specification forbids shortcuts and demands that problems be
explained. This file therefore records every error that was made while the project was
carried out, including errors that were corrected before anything was published. For
each error it states what was wrong, how it was detected, what was done, and where the
corrected statement can be checked. An error that is not listed here and is found later
is to be added, not silently repaired.
